# Pembaruan akurasi GPS presensi, 29 Oktober 2026

Batas akurasi web dan API menjadi 150 meter. Pembacaan GPS asli tetap dikirim apa adanya. Radius kantor tetap 100 meter; waktu pengambilan, penolakan lokasi tiruan, dan koordinat kantor tidak diubah. Kebijakan API ini juga berlaku untuk klien Android yang menggunakan API yang sama.

Verifikasi: 14 tes web dan 14 tes backend (termasuk tes induk) lulus. Angka 136 dan 150 diterima pada koordinat kantor; lebih dari 150 ditolak pada masuk/pulang. Titik di luar radius tetap ditolak. Database produksi tidak dipakai dalam pengujian. Pemeriksaan sintaks JavaScript berhasil. Tidak ada perubahan layout atau aset gambar.

Script deploy menemukan proses Node.js pada port 5010 dan service systemd-nya sebelum mengubah file. Jika tidak dapat dikenali, script berhenti tanpa menulis. Script hanya mengganti satu validasi akurasi yang cocok dengan source pengujian dan dua file web; tidak menimpa seluruh backend. File sebelumnya dicadangkan ke /var/backups/presensi-accuracy-150-*. Tidak ada migration, seed, perubahan .env, atau perubahan Nginx/Tunnel.

Dari PowerShell pada folder project Simasta:

```powershell
scp storage/app/private/deploy/presensi-accuracy-150-2026-10-29.tar.gz USER_SSH@HOST_SERVER:~/
ssh USER_SSH@HOST_SERVER
```

Di SSH:

```bash
mkdir -p ~/presensi-accuracy-150-2026-10-29
tar -xzf ~/presensi-accuracy-150-2026-10-29.tar.gz -C ~/presensi-accuracy-150-2026-10-29
sudo bash ~/presensi-accuracy-150-2026-10-29/deploy.sh
```

Jika script berhenti karena source/service berbeda, jangan melanjutkan penggantian file manual. Kirim pesan errornya untuk menyesuaikan dengan instalasi server. Setelah berhasil, Ctrl+Shift+R pada laptop, atau tutup dan buka kembali halaman pada HP. Lakukan Cek lokasi sebelum mencoba presensi nyata. Angka akurasi yang memenuhi batas belum menjamin koordinat perangkat berada dalam radius kantor.

Kode lokal sudah diubah; domain belum diperbarui sampai script deploy dijalankan di server. Deployment otomatis tidak dijalankan dari workspace ini.

# Akurasi GPS presensi 170 meter

Batas ketelitian GPS web dan API sekarang 170 meter. Radius kantor tetap 100 meter. Nilai akurasi asli tetap dikirim; tidak ada perubahan koordinat, waktu, data presensi, atau .env. Kebijakan API juga berlaku pada klien Android yang menggunakan layanan yang sama. Impor modul memakai versi 20261029-gps170-r1 agar tidak memakai modul 150 yang masih tersimpan.

Verifikasi: 14 tes web/domain dan 14 tes backend (termasuk tes induk) lulus. Angka 159 dan tepat 170 diterima di koordinat kantor; 170.01 ditolak saat masuk/pulang. Titik di luar radius tetap ditolak. Uji browser memuat modul tanpa versi bernilai 150, kemudian membuktikan modul berversi menggunakan 170. Pengujian tidak menulis data presensi produksi. Pemeriksaan sintaks JavaScript/Bash/Python berhasil. Tidak ada perubahan layout atau gambar.

Paket mencadangkan file server sebelum memperbarui tiga aset web dan satu baris validasi API. Script memeriksa identitas service pada port 5010, isi validasi API, dan checksum web sebelum menulis. Jika berbeda, script berhenti tanpa menulis. API direstart untuk membaca batas baru; tidak ada migration atau restart Nginx/Tunnel.

PowerShell laptop dari folder Simasta:

```powershell
scp storage/app/private/deploy/presensi-accuracy-170-2026-10-29.tar.gz USER_SSH@HOST_SERVER:~/
ssh USER_SSH@HOST_SERVER
```

Di SSH:

```bash
mkdir -p ~/presensi-accuracy-170-2026-10-29
tar -xzf ~/presensi-accuracy-170-2026-10-29.tar.gz -C ~/presensi-accuracy-170-2026-10-29
sudo bash ~/presensi-accuracy-170-2026-10-29/deploy.sh
```

Sesudah berhasil, muat ulang halaman presensi dengan Ctrl+Shift+R, lalu lakukan Cek lokasi. Jika script error, kirim pesan tersebut sebelum melanjutkan. Source lokal sudah diubah; server belum diubah sampai script deploy dijalankan di SSH.
